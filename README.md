# Fiabilidad · Psicometría (Seminarios 2 y 3)

Material interactivo de **Fiabilidad** (Psicometría, Grado en Psicología) listo para publicar en la web.

## Qué incluye

| Sección | Descripción |
|---|---|
| `presentacion/` | **47 diapositivas**: teoría previa de cada actividad, enunciados literales del seminario, respuestas numeradas (1.a, 2.b, 3.1.a…) en naranja, nomenclatura, hojas de respuestas y buscador. |
| `ejercicios/` | **34 ejercicios inversos** (te dan el resultado y hay que despejar), con nombre de cada fórmula, leyenda de símbolos, despeje paso a paso, desarrollo y respuesta. |
| `ejercicios/teoria.html` | Teoría mínima en 6 bloques (modelo clásico, estimación, longitud, variabilidad, dos medidas y consistencia interna). |
| `ejercicios/formulario.html` | **22 ecuaciones** con todas sus letras despejadas. |
| `ejercicios/nomenclatura.html` | Qué es cada símbolo, numerador y denominador de cada razón, nombres alternativos y confusiones (σ/s, KR-20/KR-21, covarianza/correlación…). |
| `ejercicios/autoevaluacion.html` | **20 preguntas** con corrección inmediata y puntuación. |

## Publicar en Vercel (3 pasos)

1. Sube este repositorio a GitHub.
2. En [vercel.com](https://vercel.com) → **Add New → Project** → importa el repositorio.
3. Framework preset: **Other**. Build command: *(vacío)*. Output directory: *(vacía, raíz)*. **Deploy**.

No necesita servidor, base de datos ni compilación: es HTML/CSS/JS estático.

## Uso local

Abre `index.html` en el navegador. Funciona sin conexión: las tipografías, KaTeX, Chart.js y GSAP están incluidos.

## Créditos

Material didáctico basado en los ejercicios de clase de **Fiabilidad (I) y (II)** · Prof.ª María José Quesada Rodríguez.
